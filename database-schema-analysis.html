1. 数据库初始化与迁移概览

数据库初始化流程位于 model/main.go，主入口为 migrateDB()。所有注册到该函数的结构体均通过 GORM AutoMigrate 自动建表或加列。

特殊处理：SubscriptionPlan（订阅套餐表）从主 AutoMigrate 列表中分离。SQLite 环境下使用手动 ensureSubscriptionPlanTableSQLite() 建表，逐列 ADD COLUMN；MySQL/PostgreSQL 环境直接 AutoMigrate。
手动迁移：migrateTokenModelLimitsToText() 将 tokens.model_limits 从 varchar 迁移至 text；migrateSubscriptionPlanPriceAmount() 将 subscription_plans.price_amount 从 float/double 迁移至 decimal(10,6)。
日志独立数据库：当环境变量 LOG_SQL_DSN 非空时，LOG_DB 为独立数据库连接，仅迁移 Log 表。否则 LOG_DB 与 DB 指向同一数据库。
并行迁移：migrateDBFast() 采用 goroutine 并发执行各模型的 AutoMigrate，用 error channel 收拢错误。
根账户创建：首次启动时若无用户记录，自动创建 root 账户（密码 123456，额度 1 亿）。

11. 多数据库兼容说明

11.1 支持的数据库与条件分支

系统同时支持 SQLite、MySQL (>= 5.7.8) 和 PostgreSQL (>= 9.6)。在代码中通过以下标志进行分支：

  • common.UsingSQLite
  • common.UsingMySQL
  • common.UsingPostgreSQL
  • common.LogSqlType（日志库单独类型）

11.3 中文支持

MySQL 启动时会检测字符集与排序规则，必须支持中文（utf8mb4、utf8、gbk、big5、gb18030），否则启动失败。参见 checkMySQLChineseSupport()。

11.4 日志数据库独立

当配置 LOG_SQL_DSN 时，日志表 logs 写入独立的 LOG_DB 数据库。LOG_DB 可配置为与主数据库不同的类型。代码通过 logGroupCol、logKeyCol 适配不同方言。
